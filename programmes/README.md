# Programmes officiels

Référence pour créer les modules : à consulter pour savoir ce qui se travaille en CM1, CM2 et 6e.

| Fichier | Contenu |
|---|---|
| `cycle3-2023.pdf` | Programme du cycle 3 (CM1, CM2, 6e), version en vigueur à la rentrée 2023. L'original : il fait foi. |
| `cycle3-2023.md` | Le texte extrait du PDF, page par page (`<!-- page N -->`), plus facile à chercher et à lire pour Claude. La mise en page (colonnes, tableaux) peut être imparfaite. |

## Source

- Document officiel du ministère de l'Éducation nationale, publié sur Eduscol :
  https://eduscol.education.fr/document/50990/download
- Page d'origine : https://eduscol.education.gouv.fr/4356/enseigner-au-cycle-3
- Texte : BOEN n° 31 du 30 juillet 2020 (arrêté du 17 juillet 2020), avec le nouveau programme de
  sciences et technologie du BOEN n° 25 du 22 juin 2023.
- Téléchargé le 14 octobre 2026.

## Ce qui n'y est pas

Les repères annuels de progression et les attendus de fin d'année (sur Eduscol) ne sont pas
dans ce dossier : le site bloque les téléchargements automatiques.

## Si le programme change

Remplacer les deux fichiers (nouveau nom avec l'année) et mettre à jour ce fichier. Ne pas
modifier le texte à la main : c'est une copie du document officiel.
